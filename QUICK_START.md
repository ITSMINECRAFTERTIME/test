# Sigma Spy - Quick Start Guide 🚀

## ⚡ 30-Second Setup

### Step 1: Copy Loadstring
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Dexz00/Sigma-Spy/main/Main.lua"))()
```

### Step 2: Paste in Executor Console
1. Open your Roblox executor
2. Paste the code above
3. Press Execute

### Step 3: Click "Yes" When Prompted
```
Enable function patches?
Yes | No
```

**✅ Done!** Sigma Spy is now running.

---

## 📖 Using Sigma Spy

### Main Window
- **Logs Tab:** Shows all remote calls
- **Filter:** Search for specific remotes
- **Pause:** Stop logging new calls
- **Clear:** Clear current logs

### Remote Information
Each log entry shows:
- **Method:** `FireServer`, `InvokeServer`, `OnClientEvent`, etc.
- **Remote:** The remote name/path
- **Arguments:** What data was sent
- **Caller:** Where the call came from
- **Timestamp:** When it happened

### Controls

| Action | Control |
|--------|---------|
| Toggle UI | Check keybind in settings |
| Pause Logging | `Q` (default) |
| Clear Logs | Right-click → Clear |
| Export Logs | Right-click → Export to File |

## 🔧 If Something Goes Wrong

### Problem: "attempt to index nil" Error
**Fix:** You're using old code. Use `SigmaSpy_WORKING.lua` instead.

### Problem: Communication Library Errors
**Fix:** 
1. Create file: `Sigma Spy/Config.lua`
2. Add:
```lua
return {
    ForceUseCustomComm = true
}
```

### Problem: No Logs Showing
**Steps:**
1. Make sure Pause is OFF (Q key)
2. Trigger a remote call in the game
3. Check if it appears in logs
4. Try a different game first for testing

### Problem: Script Won't Load
**Steps:**
1. Check internet connection
2. Wait 30 seconds
3. Try again
4. Check GitHub is accessible

## 🎮 Example: Inspecting a Game

### Game: Any Roblox Game with Remotes

**Goal:** See what remotes are being called

**Steps:**
1. Load Sigma Spy
2. Click "Yes" for function patches
3. Play the game normally
4. Every remote call appears in the log
5. Click on any entry to see details

**Example Output:**
```
RemoteEvent: "Combat/Attack"
  Args: [Vector3(10, 5, 0), "Sword"]
  From: LocalScript in StarterPlayer
  Time: 14:23:45
```

## 📊 Common Remotes

### Most Games Have:
- `OnClientEvent` - Server → Client messages
- `FireServer` - Client → Server requests
- `InvokeServer` - Client requests with response
- Custom named remotes - Game specific

### What to Look For:
- **Money/Currency** remotes (test security)
- **Player Data** remotes (see what's synced)
- **Game State** remotes (understand flow)

## 💾 Export Your Logs

### Save to File
1. Right-click in logs panel
2. Select "Export to File"
3. File saved to: `Sigma Spy/Logs/`

### File Format
```
-- Log Dump - Generated by Sigma Spy
-- Game: [Game Name]
-- Date: [Date/Time]
-- Version: 12.0.1

-- [14:23:45] RemoteEvent: Combat/Attack
--   Args: [Vector3, String]
--   Return: nil
```

## 🚫 Blocking Remotes (Advanced)

### Block Specific Remote
```lua
-- In Sigma Spy Console
print(Spy.Block.Combat/Attack")
```

### Unblock Remote
```lua
print(Spy.Unblock("Combat/Attack"))
```

## 🔒 Important: Anti-Cheat

### Some Games Detect:
- Function hooks
- Memory modifications
- Remote inspection

### Safer Usage:
1. Test on unprotected games first
2. Don't export logs publicly
3. Don't use against competitive games
4. Always have permission

## 💡 Tips & Tricks

### Tip #1: Filter Long Names
If remotes have long names, use search:
- Search: `Combat`
- Shows: All remotes with "Combat" in name

### Tip #2: Pause When Needed
Press `Q` to pause logging when game gets busy

### Tip #3: Use Multiple Windows
Run multiple Sigma Spies to monitor different games

### Tip #4: Sort by Type
Click column header to sort remotes by:
- Name
- Type (FireServer, OnClientEvent, etc.)
- Timestamp
